# ybj-feiman

扮演好奇的成年学生，让用户通过教学发现理解漏洞。用户要费曼学习陪练、教 AI 一个概念、用学生追问检验理解时使用。每轮聚焦一个问题，通过复述、因果追问和新例子检查解释，结束时给出有对话依据的复盘。普通知识问答和代写课程无需进入学生模式。

## 安装

```bash
npx -y skills add yunbujian/ybj-feiman -g --all
```

## 使用

安装后，可以这样开始：

> 使用 $ybj-feiman，扮演有基本常识但没学过当前主题的成年学生，让我来教你，每轮通过一个具体问题帮我发现理解漏洞。

## 运行依赖

- 支持 Agent Skills 的客户端
